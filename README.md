My keyboard layouts. I'm typing Turkish language texts sometimes - on English-only keyboard.

# macOS

Own layout for MacBook (thanks to authors of Ukelele app!):
- ö is generated by Option-O
- ı is generated by Option-I
- ü is generated by Option-U
- ş is generated by Option-S
- ç is generated by Option-C
- ğ is generated by Option-G

Add Shift for the capital letters (Shift-Option-I gives İ).

Also Tilda button produces plain tilda now - no more dead key.
The button § also produces the same tilda.

Two differences from the Windows and Linux layouts: the remaining
US-International dead keys are still there (`'`, `"`, Shift-6 `^`, Option-E,
Option-N), and Caps Lock does not reach the Turkish letters - with Caps Lock on,
Option-S/G/O/U/I still give the stock US-International characters.

After installation of bundle (just double click on it) - you may need to restart the app.

# Windows

The same layout for a generic ANSI (US) keyboard lives in the `windows` folder.
Here AltGr (Right Alt) plays the role of the Mac Option key:
- ö is generated by AltGr-O
- ı is generated by AltGr-I
- ü is generated by AltGr-U
- ş is generated by AltGr-S
- ç is generated by AltGr-C
- ğ is generated by AltGr-G

Add Shift for the capital letters (AltGr-Shift-I gives İ). Everything else is the
stock US layout; tilde is already a plain key on Windows, so no dead-key fix is needed.

To install: run `windows/prebuilt/install.cmd` (asks for admin rights), then add the
"US Intl - TR" keyboard in Settings > Time & Language > Language & region >
English (United States) > Language options. Sign out and back in if it does not appear.
`uninstall.cmd` removes it again.

The layout source is `windows/US-TR.klc` - it can be opened and rebuilt with
Microsoft Keyboard Layout Creator 1.4 (which can also produce a regular MSI
installer via Project > Build DLL and Setup Package).

# Linux

The same layout as an XKB layout, in the `linux` folder. AltGr (Right Alt) plays
the role of the Mac Option key, exactly as on Windows:

```
                 AltGr        AltGr+Shift
      U     ->     ü               Ü
      I     ->     ı               İ
      O     ->     ö               Ö
      S     ->     ş               Ş
      G     ->     ğ               Ğ
      C     ->     ç               Ç
```

Left Alt is untouched, so application shortcuts keep working. Caps Lock also
capitalises the AltGr letters, so Caps Lock + AltGr-I gives İ. Everything else
is the stock US layout - tilde is a plain key and there are no dead keys at all.

To install:

```sh
./linux/install.sh      # asks for sudo itself
```

It compiles the layout first and refuses to install a broken one, copies
`linux/symbols/ustr` to `/usr/share/X11/xkb/symbols/ustr`, registers it in the
XKB rules registry, and replaces `us` with `ustr` in your layout list. After
that it shows up as "English (US, Turkish letters, AltGr)" in System Settings >
Input Devices > Keyboard > Layouts. Pass `--no-configure` to install it without
touching your layout list.

`./linux/selftest.sh` checks that all six keys really produce the right
characters, both from the installed file and from what the X server has loaded.
`./linux/uninstall.sh` removes everything again.

One caveat: the registry files (`evdev.xml`, `evdev.lst`, `base.xml`,
`base.lst`) belong to the `xkb-data` package, so upgrading it drops the entry
and the layout disappears from the settings list. The symbols file itself always
survives. Just re-run `install.sh` - or copy `linux/apt-hook/99-ustr-xkb` to
`/etc/apt/apt.conf.d/` (edit the path inside it first) to have it re-registered
automatically after every upgrade.

Tested on Ubuntu 24.04 / X11 / KDE Plasma 5.27.
