My keyboard layouts. I'm typing Turkish language texts on MacBook sometimes - on English-only keyboard.
So I've created own layout (thanks to authors of Ulkelele app!):
- ö is generated by Option-O
- ı is generated by Option-I
- ü is generated by Option-U
- ş is generated by Option-S
- ç is generated by Option-C
Other characters are not oftenly use in modern Turkish texts; so I missed them.

Also Tilda button produces plain tilda now - no more dead key.
The button § also produces the same tilda.

After installation of bundle (just double click on it) - you may need to restart the app.
